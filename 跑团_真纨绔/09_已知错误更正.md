# 09 已知错误更正
- 第 63 轮：原来写苏棠说“上周五钱馆找她谈话”，错了。贺骁和苏棠 9/25（周五）才认识，“上周五”是 9/19。以这里为准：钱慧芳是 9/26（周六）下午打苏棠私人手机，说展览可能提前一周。GM 写时间词之前要先对日历。
- 贺家的级别（玩家纠正）：原来写“爷爷退下来前在省里任职”“韩立山是爷爷的老部下，在他手下当过处长”，贺家被写低了，谁都能找上门。以这里为准：爷爷副国级退休；大伯在北京任正部级；韩立山是正处，够不着爷爷。
  - 第 7 轮改：韩立山没有直接跟爷爷通电话，是通过老秘书递的话，爷爷让人回了话，认赔医药费。
  - 第 73 轮改：韩立山打给爷爷的老秘书，低声下气地问老领导是不是有话要带。秘书递进去以后，爷爷自己决定给贺骁打电话，也是他自己决定回“有，是我让我孙子带的话”。其余不变。
  - 钱慧芳说“当年远远见过他一回，台上讲话几百人没人敢咳嗽”，保留。
- 韩嘉树为什么敢去贺氏找昭宁（玩家选 B）：城北真正的对手是一家外地大公司，背后有京里的关系；韩嘉树是被推到前面的棋子。第 26–29 轮的剧情不改，意思按这条理解。
- 第 76–80 轮：GM 搞旧案、查档案、铅笔字，玩家嫌没意思。处理：旧案交给爷爷在后台办，不再展开；以后只一句话报结果。
- 第 81–95 轮前后：几乎每轮结尾都塞一条新消息或一个新人，玩家嫌强推剧情。以后闲着的场景就写闲着。
- 第 107 轮：亲密戏用“……”加“后来”直接跳到了事后，违反规矩里“亲密戏不许跳，不许快进，不许用（略）糊洞”那条。已经重写中间一段：对话、情绪、笑场、停顿、谁先开口都写出来，只不写露骨的身体描写和过程本身。
